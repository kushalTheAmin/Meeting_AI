# Icons

This directory contains PWA icons for Voice Notes AI.

## Icon Requirements

- **icon-192.png**: 192x192 pixels
- **icon-512.png**: 512x512 pixels

## Generating Icons

You can generate proper icons using:

1. **Online Tools**:
   - [RealFaviconGenerator](https://realfavicongenerator.net/)
   - [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator)

2. **Design Tools**:
   - Figma, Adobe Illustrator, or Canva
   - Export at 192x192 and 512x512 with transparent background

3. **Quick SVG to PNG**:
   - Create an SVG with a microphone icon
   - Use tools like `sharp` or ImageMagick to convert to PNG

## Placeholder Icons

The current icons are placeholders. Replace them with branded icons before deploying to production.
